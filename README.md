# 잿빛 성채의 도박사 — 테스트 빌드

수명을 걸고 운명의 카드를 뽑는 몰락한 도박사 렌이, 좀비 역병에 무너진 왕국을 하룻밤씩 지켜내는 턴제 레인 디펜스 + 덱빌딩 카드 게임입니다.

이 저장소는 **테스트 APK를 나눠 주는 곳**입니다. 게임 코드는 들어 있지 않습니다.

## 설치

1. 오른쪽 **Releases**에서 가장 위(최신) 버전을 엽니다.
2. `AshenGambler_*.apk`를 폰에서 받아 엽니다.
3. 처음 깔 때 '출처를 알 수 없는 앱 허용'이 필요할 수 있습니다.

- 안드로이드 8.0 이상, 세로 화면
- 테스트 빌드라 저장은 폰 안에만 남습니다. 새 버전을 덮어 깔면 이어서 할 수 있습니다.

## 의견 보내기

플레이하며 느낀 점, 막힌 곳, 글자가 잘린 화면(폰 기종 + 스크린샷)을 해찬에게 보내 주세요.
